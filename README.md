# Мои записи — PWA

Локальный дневник мыслей, чувств и идей с автоматической фиксацией даты и времени.

## Развертывание через GitHub Pages
1. Создайте новый публичный репозиторий GitHub, например `moi-zapisi`.
2. Загрузите **содержимое** этой папки в корень репозитория (`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, папку `icons`).
3. В Settings → Pages выберите `Deploy from a branch`, ветку `main`, каталог `/ (root)` и сохраните.
4. Откройте полученный HTTPS-адрес. В Chrome на Android установите приложение через меню браузера; на iPhone — Safari → «Поделиться» → «На экран Домой».

## Данные
- Дата и время создания сохраняются автоматически по системному времени устройства в ISO 8601 UTC; показываются в локальном времени устройства.
- Записи хранятся в localStorage текущего браузера, без серверной синхронизации.
- Экспорт JSON содержит `format`, `version`, `exported_at`, `entries` (`id`, `type`, `text`, `created_at`, `updated_at`).
- Импорт добавляет только записи с новыми `id`, не перезаписывая существующие.
- Экспортируйте резервную копию регулярно, особенно перед чисткой данных браузера/сменой телефона. Не используйте приватный режим.
- Для анализа отправьте экспортированный JSON в ChatGPT. Публиковать JSON в GitHub НЕ нужно: там личная информация.

## Важно
PWA работает офлайн после первого успешного открытия через HTTPS. Разные браузеры и устройства не обмениваются записями автоматически. Для переноса используйте экспорт/импорт JSON.
